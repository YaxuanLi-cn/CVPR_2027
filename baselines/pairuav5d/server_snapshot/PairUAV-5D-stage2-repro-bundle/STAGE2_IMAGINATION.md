## 0. 起点与误差拆解（2026-11-15）

第一阶段最终结果（结果集 31,273 对；test 6,364 对，tour 不相交）：

| | MAE_x | MAE_y | MAE_z | MAE_tilt | MAE_heading | MAE_distance |
|---|---:|---:|---:|---:|---:|---:|
| 第一阶段（不做范数缩放的版本） | 1.3750 | 1.3441 | 0.7899 | 0.4417 | 0.1212 | 0.9989 |
| 上界：同样的融合 + 真实绝对朝向 | 0.8967 | 0.8876 | 0.7899 | 0.4417 | 0.1212 | 0.9989 |

世界系 `(x, y) = Rot(ĥ_a) · (lx, ly)`：`(lx, ly)` 是相机 a 水平坐标系里的位移（来自 SuperGlue 几何 + 融合），`ĥ_a` 是相机 a 的绝对朝向（单图 CNN）。
所以 x/y 的误差有两个来源，我在 test 上把它们拆开了：

### 0.1 来源一：绝对朝向 ĥ_a（占 x/y 误差的大头）

- 合并 a、b 两张图后的绝对朝向误差：均值 5.75°，中位数 1.64°，分位数 75% / 90% / 95% / 98% / 99% = 4.4° / 10.7° / 17.1° / 39.8° / 128°。重尾。
- 按绝对朝向误差分桶，看「x/y 比上界多出来的那部分误差」由谁贡献：

| 绝对朝向误差 | 对数 | x/y 平均 MAE | 上界 | 占多出误差的比例 |
|---|---:|---:|---:|---:|
| 0–1° | 2276 | 0.84 | 0.84 | 0.3% |
| 1–2° | 1229 | 0.98 | 0.94 | 1.7% |
| 2–5° | 1417 | 1.05 | 0.88 | 8.2% |
| 5–10° | 745 | 1.48 | 0.96 | 13.2% |
| 10–20° | 441 | 2.16 | 0.95 | 18.0% |
| 20–45° | 138 | 3.79 | 1.06 | 12.7% |
| >45° | 118 | 12.39 | 0.79 | **46.0%** |

- 误差大部分是 **tour 级别的系统偏差**，而不是单张图的随机噪声：
  - 只保留每个 tour 的平均偏差（去掉图像级噪声）：x/y = 1.290 / 1.291（几乎没降）；
  - 只保留图像级噪声（去掉 tour 偏差）：x/y = 1.093 / 1.082。
  - 290 个测试 tour 里有 15 个 tour 的平均误差 >20°，它们贡献了总绝对朝向误差的 45%。
- 南半球的 tour（测试图像的 1%，170 张）误差 128°：影子方向与北半球相反，训练集里南半球只占 0.8%，CNN 学不到。
- 置信度 κ 是有信息量的：κ 最低的 1/8 样本误差 25.6°，最高的 1/8 只有 0.9°。

**重要的原理性限制**：一对图像之间的任何比对（包括「想象目标图再和真实目标图比」）只能约束**相对**位姿 `(lx, ly, z, Δheading, tilt)`；
世界系的朝向在一对图像内部不可观 —— 把候选 `(x, y)` 绕原点整体旋转、同时相应改变 ĥ_a，想象出来的目标图完全一样。
所以绝对朝向只能来自单图的先验线索（影子、街道网格），想象模块要在这上面起作用，必须带一个「学出来的世界系先验」。

### 0.2 来源二：相对几何 (lx, ly)

test 上 `(lx, ly)` 的平均 MAE 0.873 m。若水平位移的**长度**换成真值（方向不变）：0.575；若**方向**换成真值（长度不变）：0.630。尺度和方向各占一半左右。
按 zoom pass 的内点数分桶：

| zoom 内点数 | 对数 | (lx,ly) MAE | 占相对误差的比例 | 距离相对误差 |
|---|---:|---:|---:|---:|
| <30 | 78 | 5.05 | 7% | 20% |
| 30–100 | 219 | 3.30 | 13% | 17% |
| 100–200 | 571 | 1.92 | 20% | 10% |
| 200–400 | 1784 | 1.00 | 32% | 7.0% |
| 400–800 | 2518 | 0.50 | 23% | 3.8% |
| ≥800 | 1194 | 0.26 | 6% | 2.5% |

- 内点越多，方向和尺度都越准（≥800 内点时距离相对误差只有 2.5%）。也就是说相对几何的精度仍然受「匹配的数量和定位精度」限制，
  内点 100–400 的中等样本贡献了一半以上的相对误差 —— 这是「想象 + SuperGlue 重匹配」可以发力的地方。
- z 同理：若距离换成真值，z 的 MAE 从 0.790 降到 0.504。

### 0.3 关于直接照搬图里的扩散模型

图里的做法是训练一个位姿条件的 ControlNet/LoRA 扩散模型生成目标图，再用 MSE 选候选。我判断在这个任务上直接照搬不可行，原因是精度量级：

- 第一阶段的 x/y 误差已经在 1 m 左右。相机离地约 212 m、焦距 3325 px（原图 3686 px 宽），1 m 的位移对应原图上约 16 px，
  缩到扩散模型能处理的 512 px 宽度后只有约 **2 px**，256 px 时约 1 px。
- 扩散模型生成的图像做不到 1–2 px 的几何精度（内容对、位置差几个像素是常态），用它区分相差 1 m 的候选位姿等于在噪声里选。
  原图里的任务候选间隔是十米量级，这里细了一个数量级。
- 另外 5090 单卡上把 ControlNet 训到能用也需要以小时到天计的时间。

因此保留图里的**范式**（第一阶段预测 → 候选 → 想象图片 → 与真实观测比对 → 选择/精修），但把「想象」这一步换成**几何精确**的新视角合成：
已知内参 + 第一阶段位姿 + 地面高度先验，可以用单应变换把源图像精确地渲染到候选位姿下，精度是亚像素级的；比对用 SuperGlue 而不是 MSE。
（扩散模型作为想象器的做法先不做，除非后面有时间做对照。）

## 1. 方案

两个模块，共用同一个范式，分别对应 §0 的两个误差来源。

### 模块 A：想象目标视角 + SuperGlue 重匹配（精修相对几何 lx, ly, z, 距离）

1. 取第一阶段的位姿（Δheading、tilt_a、tilt_b、平移方向、距离、相机离地高度）作为候选。
2. **想象**：用「地面平面诱导的单应」`H = K (R − t nᵀ / d) K⁻¹` 把源图像 a 渲染成「在相机 b 的位姿下应该看到的图」b̂。
   位姿正确时 b̂ 与真实的 b 在地面上逐像素对齐（建筑物屋顶只剩很小的视差）。
3. **比对**：因为 b̂ 和 b 已经对齐，可以把重叠区切成对应的小块，**在原始分辨率上逐块做 SuperGlue**（不对齐就没法分块；
   第一阶段的 zoom pass 是把整个重叠区缩到 1280×720 匹配一次）。匹配点的残余位移就是「想象 vs 真实」的差异。
4. **精修**：匹配点映射回原图坐标，重新解 E 矩阵 + MAP 位姿，作为新的候选进入融合；残余位移的统计量作为候选可靠性特征。

预期：关键点数量成倍增加、定位精度更高（原始分辨率是 1280 画布的最多 2.9 倍）→ 平移方向和「基线/深度」更准 → lx / ly / z / 距离下降。

### 模块 B：想象规范鸟瞰图（BEV）+ 朝向候选验证（修绝对朝向 → x, y）

1. **想象**：用 SuperGlue 几何给出的单相机 tilt（X-Z-X 分解的 tilt_a / tilt_b）把图像纯旋转到正下视，得到「同一位置、tilt=0」的虚拟视图。
   纯旋转的单应对任意场景深度都是精确的。在正下视图里，「相机朝向改变 θ」严格等价于「图像绕中心旋转 θ」。
2. **候选验证**：对一组朝向候选，把鸟瞰图旋转到「若该候选正确则应为北朝上」的规范姿态，由一个在训练 tour 上学的网络给出朝向分布和置信度，
   各候选的结果按置信度合并（相当于连续旋转的 TTA）。a、b 两张图的结果再用融合后的 Δheading 合并。
3. 与第一阶段的 CNN v2 相比：v2 直接吃倾斜的原图，增广只有 8 个二面体变换，而且对倾斜图像做 90° 旋转并不对应真实的朝向变化（只在 tilt=0 时精确）。
   规范鸟瞰图上可以做**精确的连续旋转增广**，输入也去掉了 tilt 这个干扰因素。

预期：能降低图像级噪声和一部分场景级失败；对 tour 级的系统偏差（太阳方位、南半球）作用有限，这部分是单图线索的固有歧义。

### 验证口径

- 测试集沿用第一阶段结果集的 test 部分（或其随机子集），所有对比都在同一批样本上。
- 基线 = 第一阶段最终预测（`half_zoom_pred.pkl` + 绝对朝向 v2）。
- 超参只在训练集 OOF / 验证 tour 上选。

`imagine_geom.py`（位姿 + 候选验证分数）、`eval_pilot.py`。SuperPoint / SuperGlue 权重不变（outdoor）。

- 引导位姿 = 第一阶段融合结果：Δheading、两台相机的 tilt（几何解，并与融合后的 Δtilt 对齐，MAE 约 0.5°）、度量位移 `(lx, ly, z)`、

1. **想象 + 重匹配明显有效**：内点数中位数 436 → 2900，平移方向误差中位数 1.08° → 0.37°、均值 11.5° → 3.9°（MAP），Δheading 均值 1.55° → 0.09°，Δtilt 均值 1.38° → 0.39°。
   所有内点区间都有改善，§0.2 里贡献了一半以上相对误差的中等样本（100–400 内点）改善最大。

## 3. 第二阶段融合的做法与冒烟测试

`stage2_imagination/stage2_fusion.py`：在第一阶段预测的基础上做精修（不是重训第一阶段）。每个目标的候选是
「第一阶段融合预测 / 想象重匹配的 E 矩阵解 / 想象重匹配的 MAP 解」（距离另加「想象匹配的三角化 × 相机高度先验」「× MASt3R 度量深度」几个尺度候选），
沿用第一阶段的机制：GBDT 预测每个候选的误差 → 按预测误差的逆平方加权混合 → L1 残差 GBDT。新增的特征：

- 想象匹配的几何质量（内点数、残差、覆盖等）；
- **候选验证分数**：把第一阶段产生过的每个位姿候选（pass-1 E / MAP、zoom E / MAP、第一阶段融合位姿）拿到「想象图 vs 真实图」的匹配点上打分
  （落在该候选对极几何 1.5 px / 3 px 以内的匹配比例、残差中位数）—— 对应参考图里「对每个候选算一个与目标图的差异」；
- 想象图与真实图的残余位移统计（想象得准不准）。

训练行用的是第一阶段按 tour 分组的 OOF 预测，所以第二阶段在训练时看到的输入和测试时是同一种东西。

冒烟测试（想象匹配刚跑完的头 716 对：train 489 / test 227，样本太少，只说明流程通了、方向对）：
heading 0.090° → 0.033°，tilt 0.354° → 0.173°，距离 0.914 → 0.758 m，z 0.703 → 0.635 m，lx / ly 0.732 / 0.875 → 0.465 / 0.492 m。
正式数字等 9,000 对跑完后给出。

## 4. 模块 B 进度：规范鸟瞰图上的绝对朝向

`stage2_imagination/bev_heading.py`。为了和第一阶段的 CNN v2 做干净的对比，其余设置全部相同（ConvNeXt-Small、256×256 输入、同样的 15.1 万张训练图、10 epoch、同样的学习率和 von Mises 输出），
只改两件事：输入换成「想象的正下视鸟瞰图」，增广换成精确的连续旋转。实现上不需要新的图像缓存：纠正 tilt、旋转、缩放、平移合成一个单应，在 GPU 上对原有的 448×256 缓存做一次 `grid_sample`。

- 训练时 tilt 用训练 tour 的 KML 标签加 1° 高斯噪声；验证 / 测试时 tilt 来自第一阶段 SuperGlue 几何（每对各自的估计，MAE 约 0.52°），不使用任何标签。
- 鸟瞰图以光轴落地点为中心，倾斜越大地面分辨率取得越粗（0.6 m/px ÷ cos tilt）。
- 推理时的候选验证：12 个等间隔的朝向候选 × 镜像，每个候选渲染一张旋转后的鸟瞰图过网络，24 个 von Mises 输出合并。
- 渲染正确性检查：同一 tour 里 tilt = 0° / 15° / 30° / 45°、朝向各不相同的 4 张图，各自渲染成「北朝上」的鸟瞰图后街道方向一致。

训练中（单视图、不做候选合并、GT tilt、3000 张抽样；v2 同期数字是中心裁剪无 TTA）：

| epoch | BEV：val MAE / 中位 | BEV：test MAE / 中位 | v2 同期：val | v2 同期：test |

## 6. 模块 B 结果：想象鸟瞰图上的绝对朝向

训练完成（10 epoch，约 47 分钟，GPU 与模块 A 的匹配共用）。单张图的绝对朝向误差（val / test 的 pair 条目，即结果集里 val 4,934、test 12,728 个「对 × 侧」；tilt 用第一阶段 SuperGlue 几何的估计）：

| 模型 | val MAE / 中位 | test MAE / 中位 |
|---|---|---|
| 第一阶段 CNN v2（原图，24 次二面体 TTA；全部 val / test 图像） | 4.5° / 1.6° | 6.8° / 2.0° |
| BEV，单视图（不做候选验证） | 4.91° / 1.47° | 7.26° / 1.90° |
| **BEV，12 个朝向候选 × 镜像** | **3.95° / 1.20°** | **6.49° / 1.59°** |
| BEV，候选验证，tilt 换成真值（上界参考） | 3.96° / 1.19° | 6.46° / 1.59° |

- 用 SuperGlue 估计的 tilt 和用真值 tilt 几乎没有差别（6.49° vs 6.46°），第一阶段的 tilt 精度对这一步足够。
- 候选验证（多个朝向候选的想象图一起打分）比单视图好：test 7.26° → 6.49°。
- 中位数明显变好（2.0° → 1.59°），均值改善有限（6.8° → 6.49°）。

接到最终的 x / y 上（test 3,000 对，相对几何用模块 A 的结果，a、b 两图合并后）：

| 绝对朝向来源 | 合并后误差 均值 / 中位 | x / y 平均 MAE | 只保留图像级噪声时 | 只保留 tour 级偏差时 | 去掉南半球 30 对后 |
|---|---|---:|---:|---:|---:|
| CNN v2（第一阶段） | 5.67° / 1.69° | 1.0245 | 0.709 | 0.941 | 0.887 |
| BEV | 5.48° / 1.29° | 1.0074 | 0.713 | 0.919 | 0.865 |
| BEV + v2 集成 | 5.27° / 1.37° | 0.9856 | 0.679 | 0.911 | 0.842 |

结论（如实说）：
- 模块 B **有效但幅度小**：x / y 再降 1.7%（单用 BEV）到 3.8%（BEV 与 v2 集成）。
- 原因和 §0.1 的判断一致：绝对朝向的剩余误差主要是 tour 级的系统偏差和少数整体失败的 tour，而不是图像级噪声。
  - 3,000 对里只有 30 对在南半球（1%），但它们把 x / y 的平均 MAE 从 0.865 拉到 1.007，一项就占了 14%。
  - 置信度 κ 最低的 1/6 样本平均误差约 21°，最高的 1/6 不到 1°。
- 更精确的输入表示（鸟瞰图 + 精确旋转增广）只能压图像级噪声，压不了「太阳方位 / 半球 / 街道网格朝向」这类单图线索本身的歧义。这部分在「逐对推理、不用外部数据」的设定下基本是硬上限。

## 8. 结论、局限与没做的事

**结论**
1. 「想象图片 → 与真实观测比对」这个范式在这个任务上有效，前提是想象这一步要几何精确。**模块 A（想象目标视角 + SuperGlue 重匹配）是主要贡献**：
   x / y −25%，z −31%，tilt −55%，heading −46%，distance −29%，六项全部显著。它用到了 SuperGlue 两次：第一阶段的 SuperGlue 位姿用来想象，SuperGlue 再用来比对想象图与真实图。
2. **模块 B（想象鸟瞰图上的绝对朝向）提升很小**：单独用不显著，与第一阶段的 CNN 集成后 x / y 再降约 4%。它压低了图像级噪声（绝对朝向中位误差 1.64° → 1.26°），
   但 x / y 剩余误差的主体是 tour 级的朝向歧义（南半球、太阳方位、街道网格走向），单图线索解决不了。
3. 现在 x / y ≈ 0.99 m，若绝对朝向为真值则是 0.49 m —— **x / y 剩余误差的一半以上来自绝对朝向**，继续提升相对几何对 x / y 的边际收益已经不大，z / tilt / heading / distance 则不受此限制。

**局限**
1. **不是全量**：测试是第一阶段结果集的全部 6,364 对（60k 划分完整测试集 12,313 对的随机一半）；第二阶段融合只用 12,000 对训练样本拟合。评测只跑了一次，没有换随机种子重复。
2. **没有照搬参考图里的扩散模型**（理由见 §0.3：1 m 的位移在 512 px 的生成图上只有约 2 px）。这里的「想象」是基于已标定内参和地面平面的几何渲染，建筑物立面等非地面内容并没有被真正「生成」。
   我没有实际训练扩散模型来验证这个判断，它是基于精度量级的推断。
3. **依赖数据集先验**：沿用第一阶段的固定内参、roll = 0、相机离地约 220 m；地面单应假设场景近似平面（高层建筑密集处想象图的视差更大，靠 SuperGlue 的容忍度吸收）。换数据集需要重新标定。
4. **成本**：想象重匹配约 0.2–0.5 s/对（平均 4.8 个 1280×720 的块，各做一次 SuperPoint + SuperGlue），是第一阶段 zoom pass 的约 5 倍。
5. 绝对朝向对南半球样本基本失效（测试里约 1% 的对，却贡献了约 14% 的 x / y 误差），第二阶段没有解决这个问题。
6. 难例仍然存在：第一阶段内点 <100 的 297 对（4.7%）虽然 (lx, ly) 误差从 3.76 降到 2.41 m，仍远高于平均水平 —— 两个视锥几乎不重叠时没有东西可比对。

**没做 / 可以接着做**
- 对第一阶段结果集全部 31,273 对跑想象重匹配并用全部训练行拟合第二阶段（预计 GPU 约 1 小时），训练行翻倍后预计还会略好。
- 绝对朝向：针对南半球 / 低置信度样本的专门处理；更高分辨率的鸟瞰图输入（现在用的是 448×256 的缓存）。按现有分析，这是 x / y 剩余误差里最大的一块。
- 用扩散模型做想象器的对照实验。
