# PairUAV 图像对运动估计：方法简介

## 这项工作要做什么

给定无人机在两个位置拍下的照片，估计无人机从第一张照片到第二张照片之间移动了多远、朝哪个方向移动，以及相机转了多少。系统先从两张图里找出相同的道路、屋顶等位置，再用这些对应位置推算相机运动。

## 方法怎么工作

**第一步：找对应位置，估计大致运动。** 系统用 SuperGlue 在两张照片中寻找相同的图像位置。为了应对相机转向较大的情况，它会尝试不同的图像旋转，并结合较高分辨率和局部放大后的匹配结果。根据匹配位置和相机参数，系统估计两次拍摄之间的转向、相机俯仰变化和移动方向。单靠两张照片通常难以确定实际移动距离，因此还会结合 MASt3R 提取的距离线索，以及单张照片预测的绝对朝向，换算出世界坐标中的移动量。

**第二步：按估计结果变换照片，再做一次更细的匹配。** 系统先根据第一步的运动估计，把一张照片按地面近似平坦的假设变换到另一张照片的视角。这种变换称为“单应变换”，可以把它理解为根据相机位置和角度，对照片做有几何依据的透视调整。随后系统在两张对齐照片的重叠区域分块、以较高分辨率重新匹配特征点，再把新的运动估计与第一步结果交给融合模型，得到最终预测。

这里所说的“想象”只是用相机几何变换已有照片，不会生成新图像；代码和实验记录没有使用扩散模型或世界模型。

## 摘要

我们研究如何根据无人机在两个位置拍摄的照片，估计两次拍摄之间的移动距离、移动方向和相机角度变化。方法分为两步。首先，系统在照片中寻找相同的图像位置，并通过尝试不同旋转、提高匹配分辨率和局部放大，改善特征匹配；再结合相机参数、MASt3R 提取的距离线索和单张照片的朝向预测，估计无人机运动。其次，系统根据初步估计对照片进行几何变换，使两张照片的地面区域尽量对齐，然后在重叠区域重新匹配特征点，并融合两轮估计结果。在实验记录的一组测试中，第二步使水平和垂直移动量、相机角度变化及移动距离的平均绝对误差均低于第一步。照片变换依赖地面近似平坦的假设；本方法不使用生成式世界模型。

## 实验结果与适用范围

实验日志记录了 12,000 对训练图像和 6,364 对测试图像。第二步相较第一步，x、y、z、相机倾斜角、相对转向角和移动距离的平均绝对误差分别降低约 27.8%、27.3%、32.7%、54.6%、45.8% 和 26.4%。这是一次数据划分上的结果，不代表多次重复实验或在其他数据集上的表现。

本文档介绍的是 `SUPERGLUE_EXPERIMENTS.md`、`STAGE2_IMAGINATION.md` 及相关代码中的 PairUAV 图像对实验，不是 README 所述的 RASR 官方线上评测方法。代码中的 `train_tilt_sincos.py` 使用已提取的特征训练一个预测相机倾斜角的小模型；它不包含 DINO-R50 图像网络，也不预测前进距离。
